# Movies

I made a small movies API in Go. I can list movies, look at one, add a new one, change one, or delete one.

Movies are saved in a file, so they are still there after I restart the server. It starts with two films already in it. If I try to add a film with no title, or ask for one that is not there, it tells me.

To run it, type go run . and the server starts on port 8000.
